# 新加坡 TOTO 选号 APP（示例版）

一个无需后端、可直接打开 `index.html` 使用的轻量化选号应用。

## 功能概览

- 支持 **Ordinary / System 7 / System 8** 三种选号模式
- 支持一次生成 1~10 注号码
- 支持“幸运号”优先保留（在结果中高亮）
- 自动生成本轮“热号/冷号/奇偶分布”洞察
- 支持本地历史记录（`localStorage`）保存与清空

## 使用方式

1. 直接在浏览器打开 `index.html`
2. 选择投注类型、注数
3. （可选）输入幸运号，如 `8,18,28`
4. 点击“生成号码”
5. 如需保留本轮结果，点击“保存本次结果”

## 目录结构

- `index.html`：页面结构
- `style.css`：视觉样式
- `app.js`：选号逻辑、统计逻辑与本地存储
